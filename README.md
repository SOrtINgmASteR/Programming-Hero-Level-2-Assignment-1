## 🧩 Problem List (1–7)

1. Filter even numbers from an array
2. Reverse a string
3. Type guard: `string` vs `number`
4. Generic `getProperty` (key-safe)
5. `Book` interface + add `isRead`
6. OOP: `Person` → `Student` (inheritance)
7. Intersection of two number arrays

## ✍️ Blog Topics

- `any` vs `unknown` + type narrowing
- `Pick` & `Omit` utility types (DRY)
- Generics for reusable, typed code
- OOP pillars in TypeScript
